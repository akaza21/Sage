# Third-party notices

Sage is licensed under the Apache License, Version 2.0. It ships with
third-party components that remain under their own licenses.

Bundled dependencies are pinned in the lockfiles:

- Rust crates: `src-tauri/Cargo.lock`
- npm packages bundled into the WebView: `package-lock.json`

Automated generation of their license texts for release packages is not
implemented yet. It must exist before the first public release.

`public/harness-*.svg` identify each harness in the harness picker. They are
third-party marks that belong to their owners; their use does not imply
endorsement. Sources and licenses are listed per file in
`public/third-party/harness-logos-NOTICE.txt`, with the license texts beside it:

- Simple Icons (CC0 1.0): `public/third-party/simple-icons-LICENSE.txt`
- Lobe Icons (MIT): `public/third-party/lobe-icons-LICENSE.txt`
