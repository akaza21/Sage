# Development roadmap

The [feature roadmap](FEATURE-ROADMAP.md) records GAP-B delivery status and
remaining cross-lane dependencies. The [current state](CURRENT-STATE.md)
describes the implemented architecture without claiming acceptance evidence
that has not been collected.

Follow-up work must preserve the bounded ACP runtime in
[ADR-0007](../decisions/ADR-0007-bounded-acp-session-runtime.md), shared Agent
and Editor resources, and the product invariants in `AGENTS.md`.

GAP-B14 and the web-link portion of GAP-B15 need their cross-lane dependency
and acceptance requirements before they can be marked complete. Local
regression tests and bundle checks do not establish native visual acceptance.
